# T-12 — Contexto explícito para Ollama
**Agente:** dev-app · **Contrato:** §1 (`OLLAMA_NUM_CTX`), §7 (`chat`), §10
**Objetivo:** que ninguna llamada al LLM se trunque: `chat()` envía `options.num_ctx` leído de `OLLAMA_NUM_CTX` (default 12288).
**Archivos permitidos:** `app/soporte/ollama.py`, `tests/test_soporte_*.py`, `.env.example` (solo agregar la línea `OLLAMA_NUM_CTX=12288` con comentario).
**Criterio de hecho:**
1. Test unitario que verifica que el payload enviado a `/api/chat` incluye `num_ctx` y que respeta la variable de entorno.
2. Prueba real contra el contenedor ollama: un prompt de ~6,000 tokens devuelve `prompt_eval_count` > 5,000 (sin truncar).
