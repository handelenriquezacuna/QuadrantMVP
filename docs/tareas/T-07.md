# T-07 — Benchmark grabado
**Agente:** dev-datos · **Contrato:** §7 (benchmark), §10
**Objetivo:** generar `data/benchmark_grabado.csv` real con Ollama en el host.
**Archivos permitidos:** `ingest/benchmark.py`, `ingest/preguntas_benchmark.yaml`, `data/benchmark_grabado.csv`, `tests/test_ingest_benchmark.py`
**Notas:** se ejecuta con `docker compose run --rm app python -m ingest.benchmark` (alcanza Ollama por host.docker.internal). Vacía `answer_cache` al inicio para que el resultado sea reproducible. Modelo: el de `OLLAMA_MODEL`.
**Criterio de hecho:**
1. CSV con 200 filas (100 preguntas × 2 modos), columnas de §7, sin tokens estimados.
2. Al menos una paráfrasis con `cache_hit=True` y 0 tokens.
3. Resumen impreso: tokens totales por modo y % de ahorro.
